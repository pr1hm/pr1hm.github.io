# Terminal Monospace Favicon Design

**Feature:** Custom SVG Favicon (Terminal `[P]` Mark)  
**File:** `public/favicon.svg`  
**Palette:** Obsidian `#09090b`, Off-White `#f4f4f5`, Muted Zinc `#71717a`  

---

## 1. Overview & Geometry

The default Vite starter icon was replaced with a custom-engineered, scalable SVG favicon designed for systems developers:
- **Canvas:** 64x64 vector viewport with squircle corner rounding (`rx="16"`).
- **Background:** Deep obsidian `#09090b` with a crisp outer rim (`stroke="#27272a"`).
- **Insignia:** Developer-centric monospace terminal mark featuring opening/closing brackets `[` and `]` enclosing a high-contrast central lettermark `P` in pure off-white (`#f4f4f5`).
- **Contrast & Legibility:** Optimized for maximum visibility on dark browser themes, light tabs, mobile browser address bars, and retina displays.
